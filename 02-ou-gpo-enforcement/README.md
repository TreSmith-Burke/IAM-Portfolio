# Project 2: OU-Scoped Group Policy Enforcement

This lab simulates a creation of a GPO designated for a HR OU. The GPO applied ensures that an HR user cannot see the Recycle Bin on their desktop. A comparison of OUs with and without the GPO applied are shown in this lab. 

**Skills demonstrated:** Group policy scoping and targeting, Policy verification, Active Directory and Windows Server Administration.

## Project Scope

- [x]  GPO creation and configuration
- [x] Organizational Unit (OU) targeting
- [x] Policy scoping and verification (HR vs. IT)
- [x]  Group Policy refresh and enforcement testing
- [x]  Policy removal and reversal verification
